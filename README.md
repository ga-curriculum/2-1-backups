## About

By the end of this module, students will be able to design and implement a robust data protection strategy using the 3-2-1 backup approach, adapted for modern threats and technology environments.

## Content

| Lesson | Est. Delivery Time | Skills |
| ------ |:------------------:| ------ |
| [Data Resilience Fundamentals](./data-resilience-fundamentals/README.md)                          | 10 min | Set up the development environment. |
| [Implementation Architectures](./implementation-architectures/README.md)                    | 10 min | Review architectures that implement the 3-2-1 strategy.                |
| [Evolution and Adaptation](./evolution-and-adaptation/README.md) | 10 min | Learn how technology has changed and how the 3-2-1-1-0 adaptation can be implemented.                |
| **Total content**                                   | 30 min |                                     |
